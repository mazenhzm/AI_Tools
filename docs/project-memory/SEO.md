# SEO

## Core infrastructure

- Dynamic `generateMetadata` per page type (tool/category/collection/update/search).
- Canonical URLs on every indexable page.
- OpenGraph + Twitter card metadata; locale-aware alternates for AR (`ar`) and EN (`en`) where dual content exists.
- `app/sitemap.xml` (src: `app/sitemap.ts`) — published tools, categories, collections, static pages. Excludes non-indexable content.
- `app/robots.ts` — allow crawl, disallow `/admin`, `sitemap` reference.
- `not-found.tsx` + 404 for missing slugs; no soft-404s.
- Slug handling: single canonical slug per tool/category/collection; redirects for changed slugs (redirect via DB mapping table or Next redirects config).

## Structured data (only when factually justified)

- `SoftwareApplication` — tool page: name, description, url, category, pricing (derived from verified pricing), `publisher`, `offers` only when pricing verified.
- `WebSite` — homepage/sitewide.
- `BreadcrumbList` — tools/categories/collections pages.
- `FAQPage` — only when FAQ genuinely exists (AI content with source-derived Q&A).
- No invented reviews/ratings schema (anti-hallucination rule).

## Internal linking

- Tool pages: related tools (same category, top quality), related categories, collections containing the tool, source attribution.
- Category pages: tool listings + related categories + collections scoped to that category.
- Search/sitemap/latest-updates cross-links.
- Generated by `lib/seo/relations.ts` from DB queries — deterministic, no link stuffing.

## Programmatic pages policy

- `collections` pages are curated in admin; published only when non-empty and approved.
- Category pages must contain intro + listings + related; never thin.
- Sitemap only includes published, quality-gated content.

## Per-page requirements checklist (enforced by tests)

- canonical present and absolute
- title/meta populated (AR primary, EN available)
- OG + twitter tags present
- indexable pages are not noindex (admin/search filtered pages may be)
- JSON-LD matches facts (no review/rating fields invented)
