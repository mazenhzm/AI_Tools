# DATABASE

PostgreSQL 16. Drizzle ORM schema in `lib/db/schema.ts`; migrations generated by drizzle-kit into `lib/db/migrations/`. Constraints are enforced at the DB layer.

## Local setup

- Docker Compose `db` service: `postgres:16.4-alpine`, host port **5433**, user `aidiscovery`, password `aidiscovery_dev`.
- Databases: `aidiscovery_dev`, `aidiscovery_test` (created by `infra/pg-init/01-create-test-db.sql`; also enables `pg_trgm`).
- Scripts: `npm run db:generate`, `npm run db:migrate`, `npm run db:seed`, `npm run db:seed:admin`.
- `scripts/migrate.ts` runs `CREATE EXTENSION IF NOT EXISTS pg_trgm` then drizzle `migrate()`; it logs the target `host:port/dbname`.

### Catalog
- **categories** — `id` uuid PK, `name_ar/en`, `slug` (unique), `description_ar/en`, `seo_title_ar/en`, `seo_description_ar/en`, `parent_id` self-FK (ON DELETE set null), timestamps.
- **tools** — `id` uuid PK, `name`, `slug` (unique), `description_ar/en` (NOT NULL default ''), `short_description_ar/en`, `long_description_ar/en`, `category_id` FK (set null), `pricing_type` (default `unknown`), `pricing_verified`, `pricing_notes`, `website_url`, `affiliate_url`, `logo_url`, `is_featured`, `status` (default `draft`), `quality_score` numeric(5,2) default 0, `seo_title_ar/en`, `seo_description_ar/en`, `faq_json` jsonb, `published_at`, timestamps.
- **tags** / **tool_tags** — `tags`: name+slug unique; junction `tool_tags(tool_id, tag_id)` composite PK, cascade.
- **features** / **tool_features** — `features`: `name_ar/en`, `normalized_key` (unique); junction `tool_features(tool_id, feature_id)` composite PK, cascade.
- **updates** — `tool_id` FK (cascade), `title`, `content_ar/en`, `source_url`, `published_at`, `status` (default `draft`), timestamps. Partial unique on `source_url WHERE source_url IS NOT NULL`.
- **collections** / **collection_tools** — curated SEO lists; `collection_tools(collection_id, tool_id)` composite PK + `position`, cascade.
- **sponsored_listings** — `tool_id` FK (cascade), `placement` (default `featured`), `start_date`/`end_date` (date), `campaign_status` (default `draft`), `external_reference`.
- **affiliate_clicks** — bigserial PK, `tool_id` FK (set null), `ip_hash`, `user_agent`, `referrer`, `created_at`.

### Sources & ingestion
- **sources** — `name`, `slug` (unique), `type` (default `rss`), `url`, `active`, `adapter_key` (default `rss:generic`), `config` jsonb default '{}', `last_fetched_at`, `last_success_at`, timestamps.
- **tool_sources** — `tool_id` FK (cascade), `source_id` FK (cascade), `source_item_id`, `raw_data`, `normalized_data`, `content_hash`, `first_seen_at`, `last_seen_at`. **Unique (source_id, source_item_id)** = idempotency anchor.
- **ingestion_runs** — `source_id` FK (set null), `status` (default `running`), `started_at`, `finished_at`, `metrics` jsonb default '{}', `error`.
- **ingestion_items** — `run_id` FK (cascade), `source_id` FK (cascade), `source_item_id`, `status` (default `fetched`), `raw_data`, `normalized_data`, `tool_id` FK (set null), `error`, timestamps.

### AI & content
- **ai_processing_logs** — `tool_id` (set null), `ingestion_item_id` (set null), `kind` (default `enrich`), `model`, `prompt_version`, `input_tokens`, `output_tokens`, `confidence` numeric(5,2), `warnings` jsonb default '[]', `validated`, `failed`, `error`, `raw_response` jsonb.
- **content_revisions** — generic audit log: `entity_type`, `entity_id`, `field`, `before`/`after` jsonb, `reason` (default `admin`), `editor_id` FK administrators (set null).

### Auth & analytics
- **administrators** — `email` (unique), `password_hash`, `role` (default `admin`), `is_active`, `last_login_at`, timestamps.
- **analytics_events** — bigserial PK, `event`, `payload` jsonb default '{}'.

## Key constraints & indexes (47 total, verified against live DB)

- Unique: all `slug` columns, `tags.name`, `features.normalized_key`, `administrators.email`, `tool_sources(source_id, source_item_id)`, `updates.source_url` (partial, non-null).
- Partial: `tools_status_idx` on `status WHERE status = 'published'`.
- GIN: `tools_name_trgm_idx` on `lower(name) gin_trgm_ops`; `tools_search_idx` on `setweight(to_tsvector('simple', ...))` over name + AR/EN descriptions.
- Composite: `updates(tool_id, published_at)`, `ingestion_items(run_id, status)`, `ingestion_items(source_id, source_item_id)`, `ingestion_runs(source_id, started_at)`, `content_revisions(entity_type, entity_id, created_at)`, `sponsored_listings(campaign_status, start_date, end_date)`, analytics/affiliate `(…, created_at)`.
- FKs: cascade on owned children, `set null` on optional references (category, tool on ingestion items, editor).
- `pg_trgm` is required for the trigram index; `scripts/migrate.ts` creates it before applying migrations.

## Operational notes (learned in Phase 2)

- **Index declaration pattern**: in drizzle-orm 0.45, indexes must be declared in the `pgTable` third argument callback `(t) => [ ... ]`. Declaring `index(...).on(table.col)` outside the table makes columns plain `PgColumn`s (no `defaultConfig`) and crashes at import (`JSON.parse("undefined")`). Raw SQL expressions work fine inside the callback (e.g. `index("...").using("gin", sql\`lower(${t.name}) gin_trgm_ops\`)`).
- **Self-referencing FK**: `categories.parent_id` needs `references((): AnyPgColumn => categories.id, ...)` to break circular type inference.
- **`server-only`**: intentionally NOT imported by `lib/db/db.ts`, because scripts and the ingestion worker run under `tsx`/Node where it throws. Server-only guarding moves to route/action modules in later phases.
- **Migration ledger**: drizzle stores applied migrations in the `drizzle` schema. Dropping only `public` does not reset migrations — the test harness drops `drizzle` too.
- **Vitest globalSetup**: vitest does not set `NODE_ENV=test` in the globalSetup process; `tests/global-setup.ts` sets it explicitly before importing `lib/env`, and refuses to reset any database whose name does not end in `_test`.
